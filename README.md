## Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**, publicly available on Kaggle.

Dataset:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Please download the dataset manually and place all CSV files into the `data/` directory before running the project.
